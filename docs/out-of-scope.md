# Di luar scope

Frame berikut tidak diimplementasikan sebagai use case baru karena tidak termasuk daftar aktor/use case yang diminta:

- Pemesanan/menu pelanggan (`1:6709`).
- Status pesanan (`1:6086`).
- Dashboard/home pelanggan (`1:5974`), selain struktur navigasi yang diperlukan untuk alur kasir.
- Pembayaran QRIS, transfer bank, dan kartu sebagai proses eksternal; opsi tetap ditampilkan sesuai desain, tetapi proses backend hanya menyelesaikan pencatatan pembayaran.
